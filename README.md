## How to View Output / Run

1. **Browser Console (F12 / DevTools):**
   - Open any HTML task file directly in Microsoft Edge / Chrome.
   - Press `F12` to open Developer Tools and view console messages.
   - Verified DevTools console output screenshots for each individual task are saved under `LabX/images/taskX.png`.

2. **Using Node.js (Terminal):**
   - Navigate into any lab directory and execute any task file:
   ```bash
   node task1.js
   node task2.js
   ```
